# Family Minecraft pack updates

Pinned client update manifest for Minecraft 1.20.1 / Fabric 0.15.7.

Only mod-download references and selected pack settings belong here. Do not upload worlds, account files, player data, map history, server access lists, or backups.

The first release preserves the tested 78-mod set and disables automatic JourneyMap death markers. Existing manual waypoints and map history are not managed or deleted.

Updates are deliberate releases: validate on a copy, verify hashes, then commit the complete index and pack together. Clients check the main branch before launch. Minecraft/loader migrations require separate Prism changes; this updater does not silently migrate major game versions.
